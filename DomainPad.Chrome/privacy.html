DomainPad

Politica de confidențialitate

Ultima actualizare: 16 noiembrie 2026

DomainPad este o extensie Chrome pentru notițe private, legate de domeniul pe care îl vizitezi. Această pagină explică exact ce date ajung în extensie, unde sunt păstrate și ce nu face extensia cu ele.

Pe scurt: toate datele rămân în browserul tău, în chrome.storage.local. Extensia nu are cont, server, telemetrie și nu trimite nimic prin rețea.

Ce date prelucrează extensia

  • Textul notițelor. Conținutul pe care îl scrii tu în popup, împreună cu două momente de timp: când a fost creată notița și când a fost modificată ultima dată.
  • Domeniul paginii. Extensia citește URL-ul tabului activ când deschizi popup-ul și URL-urile taburilor pentru a actualiza badge-ul de pe iconiță. Din URL este păstrat doar domeniul normalizat, de exemplu github.com sau localhost:3000, ca cheie a notiței.
  • Limba interfeței. Alegerea RO/EN, ca popup-ul și pagina de opțiuni să pornească în aceeași limbă la următoarea deschidere.

Extensia nu citește conținutul paginilor, nu accesează cookie-uri, formulare, pagina de istoric a browserului, fișiere sau alte date ale contului tău Google. URL-urile taburilor sunt folosite doar în memorie, pentru a determina domeniul; extensia nu construiește și nu păstrează un istoric al vizitelor.

Cum sunt folosite datele

  • Domeniul este folosit pentru a găsi notița potrivită când revii pe un site.
  • Textul notiței este afișat în popup și în pagina Toate notițele.
  • Momentul ultimei modificări este folosit pentru sortarea listei și pentru afișarea datei relative, de exemplu „acum 5 minute”.
  • Limba aleasă este folosită doar pentru afișarea interfeței.

Acestea sunt singurele scopuri. Datele nu sunt folosite pentru publicitate, profilare, analiză de comportament sau cercetare de piață.

Unde sunt stocate datele

Notițele și limba interfeței sunt salvate local, în chrome.storage.local, în profilul de Chrome în care ai instalat extensia. Nu există sincronizare între dispozitive și nu există copii pe serverele dezvoltatorului.

Exportul JSON este generat în browser și descărcat ca fișier obișnuit. Fișierul rămâne sub controlul tău, pe discul tău.

Ce nu face extensia

  • Nu trimite date către niciun server, al dezvoltatorului sau al unei terțe părți.
  • Nu folosește instrumente de analiză, reclame sau urmărire.
  • Nu cere cont, autentificare sau date de plată.
  • Nu vinde și nu închiriază date.
  • Nu citește sau modifică paginile pe care navighezi.
  • Nu execută cod la distanță; tot codul este inclus în pachetul extensiei.

Permisiuni și motivul lor

Permisiune De ce este necesară
storage Singura sursă de date: notițele și limba sunt citite și scrise în chrome.storage.local.
tabs Citește URL-ul tabului pentru a determina domeniul afișat în popup și pentru a arăta badge-ul pe iconiță când domeniul are o notiță.

Extensia nu are permisiuni de acces la site-uri (host_permissions este gol) și nu injectează scripturi în pagini.

Import și export

Exportul creează un fișier JSON cu toate notițele tale, la cererea ta. Importul citește un fișier ales de tine și scrie notițele în stocarea locală. Ambele operații au loc exclusiv pe dispozitivul tău.

Păstrare și ștergere

  • Poți șterge o notiță din popup sau din pagina Toate notițele.
  • Dezinstalarea extensiei șterge toate notițele, împreună cu restul datelor extensiei din Chrome.
  • Nu există backup automat. Exportul JSON este singura cale de păstrare pe termen lung.
  • Dezvoltatorul nu deține copii ale notițelor și nu le poate recupera.

Partajare și transfer

Nu partajăm, nu vindem și nu transferăm date către terți. Nu există terți implicați în funcționarea extensiei.

Utilizare limitată

Datele sunt folosite exclusiv pentru funcționalitatea vizibilă a extensiei: afișarea notiței pentru domeniul curent, badge-ul de pe iconiță și lista tuturor notițelor. Utilizarea respectă cerințele de utilizare limitată din Chrome Web Store User Data Policy: fără publicitate personalizată, fără profilare, fără acces uman la datele utilizatorului.

Drepturile tale

Toate datele sunt pe dispozitivul tău, deci le controlezi direct: le poți citi din extensie, exporta, modifica sau șterge. Pentru întrebări despre date, folosește canalul de suport al listării extensiei din Chrome Web Store.

Modificări ale acestei politici

Dacă practicile de date se schimbă, această pagină este actualizată la aceeași adresă, iar data de la începutul paginii se modifică. Extensia nu colectează date suplimentare fără o versiune nouă, care cere acceptarea permisiunilor noi în Chrome.

Contact

Pentru întrebări despre confidențialitate, scrie prin canalul de suport al listării DomainPad din Chrome Web Store. Datele de contact ale dezvoltatorului sunt afișate public în pagina extensiei.

Privacy policy

Last updated: 16 November 2026

DomainPad is a Chrome extension for private notes tied to the website domain you visit. This page explains exactly what data reaches the extension, where it is stored, and what the extension does not do with it.

In short: all data stays in your browser, in chrome.storage.local. The extension has no account, no server, no telemetry and sends nothing over the network.

What data the extension handles

  • Note text. The content you write in the popup, together with two timestamps: when the note was created and when it was last edited.
  • The page domain. The extension reads the URL of the active tab when you open the popup, and tab URLs to update the toolbar badge. Only the normalized domain is kept from the URL, for example github.com or localhost:3000, as the note key.
  • Interface language. Your RO/EN choice, so the popup and the options page start in the same language next time.

The extension does not read page content, does not access cookies, forms, the browser history page, files or other data in your Google account. Tab URLs are used only in memory to determine the domain; the extension does not build or keep a history of the sites you visit.

How the data is used

  • The domain is used to find the right note when you return to a site.
  • The note text is shown in the popup and on the All notes page.
  • The last edit timestamp is used to sort the list and to show the relative date, for example “5 minutes ago”.
  • The selected language is used only to render the interface.

These are the only purposes. The data is not used for advertising, profiling, behavioural analysis or market research.

Where the data is stored

Notes and the interface language are stored locally, in chrome.storage.local, in the Chrome profile where you installed the extension. There is no sync between devices and there are no copies on the developer's servers.

The JSON export is generated in the browser and downloaded as a regular file. The file stays under your control, on your disk.

What the extension does not do

  • It does not send data to any server, the developer's or a third party's.
  • It does not use analytics, ads or tracking.
  • It does not ask for an account, authentication or payment details.
  • It does not sell or rent data.
  • It does not read or modify the pages you browse.
  • It does not execute remote code; all code is included in the extension package.

Permissions and why they are needed

Permission Why it is required
storage The only data source: notes and the language are read from and written to chrome.storage.local.
tabs Reads the tab URL to determine the domain shown in the popup, and to show the toolbar badge when the domain has a note.

The extension has no site access permissions (host_permissions is empty) and does not inject scripts into pages.

Import and export

Export creates a JSON file with all your notes, at your request. Import reads a file you choose and writes the notes to local storage. Both operations happen only on your device.

Retention and deletion

  • You can delete a note from the popup or from the All notes page.
  • Uninstalling the extension deletes all notes, along with the rest of the extension data in Chrome.
  • There is no automatic backup. The JSON export is the only long-term option.
  • The developer holds no copies of the notes and cannot recover them.

Sharing and transfer

We do not share, sell or transfer data to third parties. No third parties are involved in running the extension.

Limited use

The data is used solely for the extension's visible functionality: showing the note for the current domain, the toolbar badge and the list of all notes. This use complies with the limited use requirements of the Chrome Web Store User Data Policy: no personalized advertising, no profiling, no human access to user data.

Your rights

All data is on your device, so you control it directly: you can read it from the extension, export it, change it or delete it. For data questions, use the support channel on the extension listing in the Chrome Web Store.

Changes to this policy

If data practices change, this page is updated at the same address and the date at the top changes. The extension does not collect additional data without a new version that asks you to accept new permissions in Chrome.

Contact

For privacy questions, write through the support channel on the DomainPad listing in the Chrome Web Store. The developer's contact details are shown publicly on the extension page.

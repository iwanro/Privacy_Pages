1. Ce date sunt stocate și unde

Toate datele tale de afaceri — containere, clienți, închirieri, adrese, note, fotografii și coordonate GPS — sunt stocate exclusiv local pe dispozitivul tău, într-o bază de date locală. Aceste date nu sunt transmise către serverele dezvoltatorului și nu sunt stocate în cloud de către noi.

2. Notificări push (opțional)

Dacă activezi notificările, aplicația folosește un serviciu de livrare a notificărilor (Firebase Cloud Messaging) și un server intermediar (relay) pentru a te putea anunța de ridicări și întârzieri. În acest scop sunt transmise doar: tokenul de notificare al dispozitivului și conținutul minim al notificării (titlu, text, ora programată). Datele tale de afaceri complete nu sunt transmise.

3. Locație

Coordonatele GPS sunt capturate doar atunci când ceri explicit acest lucru și sunt salvate local, alături de închirierea respectivă.

4. Fotografii

Fotografiile de livrare/ridicare sunt salvate local. Dacă folosești funcția de upload de imagini, fișierul respectiv este trimis către serviciul extern imgBB folosind cheia API configurată de tine.

5. Permisiuni

Aplicația solicită: locație (pentru captura GPS), notificări (pentru reminder-e), cameră/galerie (pentru fotografii). Permisiunile sunt folosite exclusiv pentru funcțiile descrise.

6. Fără analytics, fără publicitate

Aplicația nu conține module de analytics, publicitate sau urmărire. Nu vindem și nu partajăm datele tale cu terțe părți, cu excepția serviciilor tehnice menționate (livrare notificări, upload imagini).

7. Drepturile tale

Poți oricând să ștergi datele din aplicație (individual sau toate datele) direct din aplicație. Poți dezactiva notificările și permisiunile oricând. Pentru întrebări legate de datele tale, contactează-ne la iwanro.code@gmail.com.

All your business data — containers, clients, rentals, addresses, notes, photos and GPS coordinates — is stored exclusively on your device, in a local database. This data is not transmitted to the developer's servers and is not stored in the cloud by us.

2. Push notifications (optional)

If you enable notifications, the app uses a notification delivery service (Firebase Cloud Messaging) and a relay server to notify you about pickups and overdue rentals. For this purpose only the following is transmitted: the device notification token and the minimal notification content (title, text, scheduled time). Your full business data is not transmitted.

3. Location

GPS coordinates are captured only when you explicitly request it and are saved locally with the corresponding rental.

4. Photos

Delivery/pickup photos are saved locally. If you use the image upload feature, that file is sent to the external service imgBB using the API key you configured.

The app requests: location (for GPS capture), notifications (for reminders), camera/gallery (for photos). Permissions are used exclusively for the described features.
